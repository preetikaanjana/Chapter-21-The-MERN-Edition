# Pastel Pixel Art Canvas & Gallery

An interactive 16x16 pixel art canvas editor with customizable colors, drag-to-paint inputs, bucket/flood-fill algorithms, and community publishing to a public gallery database.

## Run

```bash
# Backend (port 5000)
cd backend && npm install && npm run dev

# Frontend (port 5173)
cd frontend && npm install && npm run dev
```

Requires MongoDB running locally.
